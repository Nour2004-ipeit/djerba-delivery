# 🛡️ Djerba Delivery - Super-Admin Console

Console Web d'administration et de supervision logistique centrale pour la plateforme Djerba Delivery.

## ✨ Fonctionnalités Clés
- **Supervision Flotte & Commandes :** Vue panoramique de l'activité sur l'ensemble du territoire de l'île de Djerba en temps réel.
- **Gestion des Acteurs (RBAC) :** Approbation et gestion des comptes clients, livreurs partenaires et établissements de restauration.
- **Paramétrage Économique Équitable :** Gestion transparente du taux de commission (15%) et reporting financier.
- **Gestion des Campagnes Promotionnelles :** Configuration de codes promo et bannières publicitaires saisonnières.

## 🚀 Lancement Local
```bash
flutter pub get
flutter run -d chrome --web-port 8083
```
