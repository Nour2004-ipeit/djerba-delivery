# 👨‍🍳 Djerba Delivery - Restaurant Kitchen Dashboard

Application Web & Tablette Flutter dédiée aux gérants de restaurant et aux chefs de cuisine pour orchestrer le flux des préparations.

## ✨ Fonctionnalités Clés
- **Kanban Cuisine Temps Réel :** Visualisation immédiate en trois colonnes dynamiques (*À traiter*, *En préparation*, *Prêt pour coursier*).
- **Gestionnaire de Menu & Stocks :** Activation / désactivation immédiate de la disponibilité des plats selon les stocks de la cuisine.
- **Photographie Culinaire par IA :** Module d'enrichissement de prompt méditerranéen générant automatiquement des visuels de plats de haute qualité sans photographe.
- **Alertes Sonores & Notifications Push :** Réception immédiate des nouvelles commandes sans rafraîchissement manuel de page.

## 🚀 Lancement Local
```bash
flutter pub get
flutter run -d chrome --web-port 8081
```
